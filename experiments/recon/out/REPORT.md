# Recon decentralised-learning results (Level 1 simulation)

Generated by `experiments/recon/run_recon.py`; no hand-written numbers. EVAL seeds (terrain and hidden behaviour both vary per seed) are held out from DEV seeds 0-9. CIs: bootstrap over seeds of the paired difference.
Modes: A independent (no messages); B shares map cells + raw sightings (naive pooling); C shares map cells + exposure-corrected behaviour hypotheses with local validation. Gain = mean log-score of the true entity cell under the agent's predicted occupancy vs uniform, in nats (0 = no better than uniform).

## Honest limits

- Level 1 abstract simulation: terrain elevation here is PROCEDURAL; biome/canopy/visibility constants are synthetic assumptions, not calibrated sensors.
- Agents run in one process; the 'radio' only delivers between agents that share an up link and never reads payloads. This is not the HTTP peer transport of the DQN stack.
- Mode B's exposure assumption (peers had comparable exposure) is deliberately naive; C beating B partly reflects that design, not a general law.
- A hypothesis that looks plausible and is not contradicted by the receiver's own data is accepted: a coordinated lying peer would not be caught (only implausible/inconsistent evidence is).
- No compute offloading is implemented, so network-cost comparisons cover only local inference and messaging.
