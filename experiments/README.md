# Offline experiment harness (protocol exp-protocol-v1, task T32)

NumPy baseline only. The live PyTorch runtime (T30) reuses this protocol; add its learner factory to
`run.BACKENDS` (same signature as `_numpy_learner`) and `--backend torch` becomes selectable.

```
PYTHONPATH=packages/learning:packages/sim:experiments \
  python experiments/run.py --seeds 10 --episodes 150 --mode required --out experiments/out --report
```

`--mode` takes `required` (the five), `secondary`, `all` or explicit names. Outputs in `--out`:
`raw.jsonl` (one row per mode x scenario x seed: per-test-episode returns/coverage/ticks, budget,
per-candidate decisions, action hashes), `per_seed.csv`, `summary.json` (paired bootstrap CIs vs
`independent` and `idle`), `timing.jsonl` (wall seconds, nondeterministic), `manifest.json` (commit, seeds,
config/reward/scenario hashes, commands, UTC times, sha256 of the three deterministic files), and with
`--report` `REPORT.md` generated by `experiments/report.py` (no hand-written numbers). Reruns are
byte-identical for the hashed files.

## Modes

Required: `rule` (explorer with per-episode visit memory), `idle`, `independent`, `info_only`
(independent + map/status messages, never loads parameters), `p2p` (info_only + validated peer model
candidates through `peer.offer`). Secondary, labeled as such and not validated claims: `replay_sharing` (raw replay
rows, the T09 "information_only"), `central_online` (one shared learner; while its control link is cut
drones stay put and nothing is recorded; the cut path is node<->controller, an assumption), `ctde` (per-node
actors plus a joint-observation critic that only shapes rewards: an approximation).

All learner modes use the same reward (`rew-v0`), observation (`grid-flat-v0`), network, epsilon 0.2,
one Adam step per recorded transition, and paired world seeds: training episode i of experiment seed s uses
world seed `1000 + s*episodes + i`; validation seeds 100-104 (node-private candidate gating); frozen test
seeds 200-219. Disjointness is asserted (`harness.check_seeds`).

## Information message (info_only and p2p, identical code path)

Each tick while the peer link is up, node src sends dst: header (id, tick, battery; 4 bytes), the cells src
knows that it has not sent to dst and did not learn from dst (3 bytes each: x, y, free/wall) and newly found
markers (2 bytes each). dst merges unknown cells into its private buffer and markers into `found`.
Cells accumulate during a cut and flow after rejoin. Under `grid-flat-v0` this cannot alter any observation
(see diagnosis); the opt-in `--obs grid-flat-v1-map` exposes it.

## Scenarios (ticks within every episode; horizon 150, battery lasts 250 move ticks)

connected; partition_reconnect (peer links cut ticks 10-25; model swaps also skipped for the middle third
of training episodes); node_failure (node-1 removed before tick 20, from mid-training and always at test);
telemetry_outage (sink blocked ticks 10-25; cannot change behavior, spool counted). Episodes end early once
all 8 targets are found; the rule explorer ends no earlier than tick 27, so every fault tick is reached by
every idle and rule test episode (asserted; the per-cell `fault_reached` fraction is also reported).

## Budgets

Per cell: training episodes, env steps (world ticks), agent steps, recorded transitions (survivors only; control
link cuts excluded for central_online), optimizer updates and update samples, act calls, info/model/replay
bytes, validation episodes and env ticks. Candidate decisions list evaluations, eval ticks, bytes and scores;
wall seconds per decision are in `timing.jsonl`.

`history/` holds the pre-repair T09 artifacts (labeled). `diagnosis/` holds the idle-vs-learners study.
