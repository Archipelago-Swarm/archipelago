## Outcome

Two computers can dispatch bounded isolated work, preserve checkpoints and resume after failures without duplicate task ownership.

## Implementation slices

1. Implement the single-writer Git ledger, generation checks, path reservations and local supervisor lock.
2. Implement persisted supervisor state, bounded child invocation, explicit permissions, resource/deadline/budget admission and stop-file support.
3. Implement checkpoint/status publishing serialized with worker Git writes; preserve dirty patches and mark UNSYNCED when remote fails.
4. Handle confirmed limits using supported reset evidence or bounded backoff; distinguish auth/billing/permissions.
5. Document start/status/drain/resume commands and run a two-computer supervised trial.
