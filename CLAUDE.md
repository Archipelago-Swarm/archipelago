# Archipelago: required agent instructions

Read `agents/CONTRACT.md`, `agents/vision/roadmap.md`, and `agents/tasks/BOARD.md` before work. For a new setup, follow `agents/START_HERE.md`. For an assigned task, read its task card, latest remote handoff, and relevant architecture documents.

The contract applies to this session and every delegated coding agent. All ongoing, blocked, paused, and completed work must have a pushed Markdown handoff. A local chat transcript is not a handoff.

Do not start the overnight loop until its preflight and coordination tests pass. Do not confuse coding agents with simulated drone nodes.
