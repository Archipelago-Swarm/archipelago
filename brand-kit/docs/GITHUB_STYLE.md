# GitHub style notes

- Colors: background `#0A0A0A`, text `#EDE7DF` / `#FFFFFF`, accent `#F47B3C`, muted `#8A8A8A`, border `#333333`.
- Social preview: upload `exports/github/social-preview-1280x640.png` in the repo's Settings > Social preview (a manual step; not done here).
- README top: `exports/github/readme-banner-1600x400.png`, then the architecture, how-it-works, capability-transfer and stack figures from the same folder. Commit the PNGs you embed (this folder's `exports/` is not ignored).
- Logo: dark backgrounds use `archipelago-*-dark`, light backgrounds `archipelago-*-light`; avatar `archipelago-icon-square-1024.png`. No recoloring.
- Org/repo colors were not changed.
